# Asset licences

## Imagery — `public/images/*.webp`
All 42 images are **original artwork generated by code** for this template (`scripts/art/scenes.js`, run with
`npm run images`): procedural canvas illustrations (gradients, grain, vector silhouettes of athletes and equipment).
They contain **no third-party photographs, stock images, logos or trademarks** and no output from any AI image model.
They are owned by OneStop Infinite and supplied with the template for use in projects built from it.

**They are illustrations, not photography.** The brief for this template asked for fitness photography; no photograph
with verifiable redistribution rights could be obtained and attributed inside the build environment, so none was
included rather than inventing licence details. For a real gym, replace them with your own (or properly licensed)
photography — see CUSTOMIZATION_GUIDE.md → "Replacing images".

The six trainer "portraits" are abstract silhouettes of fictional people.

## Logo and favicon — `public/logo.svg`, `public/favicon.svg`
Original vector artwork (a stylised "V" monogram) created for this template, owned by OneStop Infinite.
The header/footer logo is rendered from `src/components/Logo.tsx` using the brand name from `src/config/site.ts`.
