# Asset licences

## Imagery — `public/images/*.webp` (46 files)
Every image is **original artwork generated by code** for this template (`scripts/art/scenes.js`, rendered with `npm run images`) using
the HTML canvas 2D API: gradients, vector shapes and procedural grain. They contain **no third-party photographs, stock images, logos,
trademarks or AI image-model output**, and no real people. They are owned by OneStop Infinite and supplied with the template for use in
projects built from it.

**Important:** these are stylised illustrations, not photography. The doctor "portraits" are cartoon-style illustrations of fictional
people. A production clinic should replace them with its own properly licensed or commissioned photography (and obtain model releases
for photographs of real staff or patients). No stock-photo licence is claimed or implied anywhere in this project.
